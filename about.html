About Genre Sense

🎯 Purpose

Genre Sense is an academic multimodal machine learning system designed to automatically classify images into semantic genres. It combines computer vision and natural language processing to analyze visual content and extracted text, providing intelligent genre predictions.

🧠 ML Pipeline

The system uses a three-stage pipeline:

  • Visual Analysis: CLIP-based image embeddings extract visual features and classify visual types (portrait, logo, poster, event, scene)
  • Text Extraction: Tesseract OCR extracts readable text from images for language-based analysis
  • Fusion & Scoring: Language-aware multimodal fusion merges vision and text signals with dynamic weighting

⚙️ Technologies

  • Backend: Python, FastAPI, SQLite
  • ML: OpenAI CLIP, Tesseract OCR, PyTorch
  • Frontend: Plain HTML, CSS, JavaScript (no frameworks)
  • Architecture: Modular, microservice-ready design

⚠️ Limitations

  • Model accuracy depends on image quality and clarity
  • OCR may struggle with handwritten text, poor quality images, or non-Latin scripts
  • Genre classification reflects training data patterns and may have cultural or contextual biases
  • Best performance on clear, well-lit images with readable text
  • Visual type classification (portrait/logo/poster/event/scene) improves genre prediction accuracy

📝 Academic Context

This project is an academic proof-of-concept demonstrating multimodal learning techniques for image classification. It showcases practical application of deep learning models, data fusion strategies, and full-stack development patterns suitable for real-world ML systems.
