ℹ️ About Genre Sense

An academic system for multimodal genre prediction using vision-language embeddings and OCR-based text analysis.

  • Tech Stack: Python, FastAPI, SQLite, CLIP, Tesseract OCR
  • Architecture: Modular ML pipeline with fusion logic
  • Version: 1.0.0
