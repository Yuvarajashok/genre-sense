# Contributing

Start with [README.md](README.md) and its linked guides.

## Report an issue

Use [GitHub Issues](https://github.com/Yuvarajashok/genre-sense/issues). Include the observed behavior, expected behavior, reproduction steps, operating system/runtime where relevant, and a minimal non-sensitive example. Remove credentials and personal data.

## Propose a change

Keep documentation and implementation changes clearly scoped. For documentation, verify paths and examples against the current source and distinguish expected behavior from actual test results. For code changes, describe the affected behavior and relevant validation; do not claim tests were run when they were not.

Screenshots should come from the actual application, with personal information removed. Do not invent metrics, supported versions, deployment URLs, or test results.

## Licensing

No license file is included. Ask the maintainer to establish licensing terms before relying on permissions not explicitly granted. This contribution guide does not select a license.
